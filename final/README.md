# ELEN90098 Combined Report and Source Code

Authors: Zhengnan Cao and Yuchen Yang

- `Combined_Report_WS2_WS3_WS4_WS5.pdf`: the four original English reports in workshop order, preceded by two linked contents pages. The merged PDF has 34 pages. The contents page numbers refer to merged PDF pages; original printed page numbers are retained.
- `Code_WS3_WS4_WS5.zip`: the organized source package for Workshops 3, 4 and 5.
- `code/README.md`: installation, layout, evaluation and reproducibility instructions, with a separate README for each workshop. Documentation and delivered source comments are in English.
- `Workshop2_Final_Report_EN.pdf` through `Workshop5_Final_Report_EN.pdf`: retained original reports.
- `Combined_Report_Outline_WS2_WS3_WS4_WS5.md`: the earlier proposed writing outline, retained for reference. It is not the contents page of the merged PDF.
- `tmp/pdfs/`: merge scripts, source manifests, rendered contents previews and verification records used to prepare this delivery.

The original 32 report pages were checked for identical extracted text and rendered pixels after merging. Report contents were not rewritten. Code organization preserves executable Python ASTs, with English translations of WS5 comments and module docstrings. Full experiment data and model weights remain in the original workshop evidence directories.
